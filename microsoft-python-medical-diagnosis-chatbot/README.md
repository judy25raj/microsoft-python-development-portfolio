## 🧠 Overview
This project implements a rule-based medical diagnosis chatbot in Python.
It simulates symptom-driven condition suggestions using structured decision logic and a lightweight knowledge base.

The system demonstrates how deterministic logic and data-driven rules can be used to build interactive decision-support tools.

## 🎯 Capabilities Demonstrated
- Rule-based inference using conditional logic
- Structured knowledge storage using JSON
- Interactive command-line interface
- Modular, readable Python design
- Input validation and flow control
