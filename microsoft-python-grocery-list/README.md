## 🧠 Overview
This project implements a lightweight Python application for managing a grocery list.  
It supports core CRUD operations—create, read, update, and delete—through clean, modular code and basic validation.

The design reflects simple business-logic services commonly used in internal tools and automation scripts.

## 🎯 Capabilities Demonstrated
- Create, update, delete, and list operations
- Input validation and error handling
- Modular Python structure
- Separation of inputs (**data/**), code (**src/**), and outputs (**results/**)

## 📂 Project Structure
```
microsoft-python-grocery-list/
├── data/          # Input files (if any)
├── src/           # Application logic
├── results/       # Output artifacts
└── README.md
```

python src/main.py
